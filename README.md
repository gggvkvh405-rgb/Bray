## Возможности

- **Вертикальные вкладки** — группы с цветовой индикацией, закрепление, перетаскивание, контекстное меню, закрытие средней кнопкой мыши и быстрое переключение на предыдущую вкладку
- **Поиск ByAzen** — фирменная страница выдачи в тёмном дизайне: фавиконки, сниппеты, «быстрый ответ». Реальные результаты без капч Google и Яндекс
- **Живые подсказки** при вводе в адресной строке и поиске
- **Прокси-режим** — открывает сайты внутри браузера, даже если они запрещают встраивание; ссылки, формы, заголовки и URL вкладок синхронизируются
- **Стартовая страница** — часы, приветствие по времени суток, погода, настраиваемые ярлыки, недавние сайты
- **Закладки** с папками, метками, заметками, сортировкой и панелью избранного; импорт/экспорт HTML и локальные резервные копии данных ByAzen
- **Коллекции вкладок** — сохранение и восстановление наборов сайтов
- **Мастерская проектов** — снимки рабочих наборов, локальная ИИ-сводка для продолжения позже, складываемые цитаты с адресами источников и временный режим «скрыть лишние вкладки»
- **Напоминания к закладкам** — заметка с причиной и выбранным временем напоминания
- **Командная палитра** (`Ctrl + K`) — поиск вкладок и действий, включая список недавно закрытых сайтов
- **Восстановление сессии и закрытых вкладок** (`Ctrl + Shift + T`); адресная строка подсказывает открытые вкладки, закладки и историю
- **Приватные вкладки** в Windows-приложении (`Ctrl + Shift + N`) используют отдельное временное хранилище и не попадают в историю/восстановление. Это не скрывает IP-адрес, а скачанные файлы остаются на диске
- **Настраиваемые сочетания клавиш** и стандартные Ctrl-комбинации браузера; предупреждение перед закрытием окна с несколькими вкладками
- **Режим чтения** с настройкой размера текста и ширины колонки; перевод, поиск выделения, копирование и сохранение текстовой копии страницы
- **Инструменты страницы** — информация, масштаб и печать; поиск по странице (`Ctrl + F`) с переходом по совпадениям; ИИ получает контекст страницы и вкладок, читает длинные страницы фрагментами, сравнивает открытые страницы и может анализировать видимый снимок интерфейса через локальную vision-модель (только после подтверждения)
- **Центр загрузок** в Windows-приложении — прогресс, отмена и продолжение прерванных загрузок, открытие файла/папки, история между запусками и быстрый доступ к папке загрузок
- **Звук вкладок** — отключение и включение звука отдельно для каждой вкладки через контекстное меню
- **Забавная мастерская** — собственные SVG-питомцы, SVG-украшения вкладок, зоопарк вкладок, случайный выбор закладки, снежный шар, мини-игра, секретный режим, след-пузырьки и тема дня (выключена по умолчанию)
- **Единый визуальный стиль** — элементы управления и декоративные детали используют встроенные SVG-иконки вместо эмодзи; внешняя загрузка значков не требуется
- **Меню страницы по правому клику** — скачать ссылку или изображение, открыть в новой вкладке, копировать адрес или выделение, искать выбранный текст; при наведении показывается адрес ссылки
- **Масштаб по сайтам** сохраняется отдельно для каждого домена и входит в резервную копию
- **Чаты ИИ** можно сохранять и искать; есть предпросмотр плана действий, отмена последней навигации и выключатель доступа ИИ к контексту сайта
- **Озвучивание и голосовой ввод** — Piper и Windows-голоса работают локально; Edge TTS доступен онлайн. Офлайн-распознавание Whisper для русского/английского устанавливается отдельно по явному нажатию, а аудиозапись не отправляется из устройства; есть выбор языка, настройка скорости, пауза/продолжение/перемотка и чтение выделенного текста с подсветкой
- **Настройка интерфейса** — высокая контрастность, компактный режим, масштаб, положение боковой панели и режим фокуса
- **Защита и обслуживание** — предупреждение об HTTP, журнал заблокированных разрешений, настраиваемая автоочистка истории по сроку хранения или при выходе, диагностика и проверка обновлений
- **Загрузки сайтов** — выбор места в системной папке «Загрузки», потоковая запись больших файлов без загрузки целиком в память, предупреждение перед запуском исполняемых файлов; в веб-версии скачивание идёт через обычный загрузчик браузера
- **Анимированный сплэш** при запуске

## Скачать (Windows)

Готовый portable-`ByAzen.exe` — в разделе [**Releases**](../../releases). Установка не нужна, просто запустите файл (Windows 10/11, x64). Данные хранятся в `%APPDATA%/ByAzen`.

> Файл не подписан цифровой подписью, поэтому SmartScreen при первом запуске может показать предупреждение: «Подробнее» → «Выполнить в любом случае».

## Локальный ИИ-помощник

ByAzen общается с локальной моделью через Ollama и понимает команды в свободной формулировке. Установите и запустите Ollama, затем откройте «ИИ» в боковой панели или нажмите `Ctrl+J`. Для новых пользователей рекомендована vision-модель `qwen3.5:4b` (примерно 3,3–4 ГБ на диске); её нужно установить через «Модели…» вручную. На ПК с 8 ГБ ОЗУ сохраняйте умеренный контекст. `qwen3.5:9b` (6,6–7,6 ГБ) потребует больше памяти, а `qwen3.8:27b` (около 18 ГБ) рассчитана на более мощные системы. ИИ может читать страницу частями, искать в ней текст, управлять безопасными элементами, работать с вкладками и проверять результат. Для актуальных сведений он может искать в интернете: в DuckDuckGo уходит только поисковая фраза, а найденные источники выводятся отдельными ссылками. На странице выдачи также показываются миниатюры из поиска по изображениям DuckDuckGo; нажатие открывает страницу-источник внутри ByAzen. Для визуального вопроса он запросит скриншот: перед захватом появляется подтверждение, снимок отправляется только локальной vision-модели и не сохраняется. Рискованные клики, отправка форм, скачивание файла и закрытие вкладки требуют подтверждения. Русские нейроголоса Edge работают через интернет и отправляют Microsoft только текст озвучиваемого ответа; Piper и установленные голоса Windows синтезируют речь на устройстве.

Модель выбирает браузерные инструменты по смыслу фразы. Помимо вкладок и поиска, она может изучать текущую страницу, читать длинный текст фрагментами, визуально осматривать снимок интерфейса после подтверждения и по видимым элементам нажимать кнопки/ссылки, заполнять текстовые поля, выбирать пункты списка и управлять флажками. Она может искать в интернете с источниками, а также непосредственно на Ozon/Wildberries/YouTube. Рискованные действия (покупка, отправка, принятие условий, подписка, скачивание и закрытие вкладки) требуют подтверждения. Произвольный код и команды ОС не выполняются.

## Модели ИИ и голосовые пакеты

В окне ИИ откройте **«Модели…»**, чтобы увидеть каталог локальных моделей Ollama. Для 8 ГБ ОЗУ рекомендована `qwen3.5:4b` с коротким контекстом; `qwen3.5:9b` разумнее пробовать при 16 ГБ и более, а `qwen3.8:27b` — на ещё более мощном компьютере. Теги и размер модели показываются в каталоге. Для загрузки нужна установленная и запущенная Ollama; выбор и установка выполняются вручную.

Кнопка **«Распознавание…»** устанавливает офлайн Whisper Base (примерно 148 МБ) для русского и английского. Загрузка модели запускается только по явному подтверждению, файл сохраняется вне каталога приложения и проверяется по SHA-256: `60ed5bc3dd14eea856493d334349b405782ddcaf0028d4b5df4088345fba2efe`. Модель хранится в пользовательских данных ByAzen; запись ограничена 30 секундами, обрабатывается локально и не отправляется в сеть. Библиотека [whisper.cpp v1.9.5](https://github.com/ggml-org/whisper.cpp/tree/v1.9.5) распространяется по MIT; SHA и размер исходной модели указаны в [карточке ggml-base.bin](https://huggingface.co/ggerganov/whisper.cpp/blob/main/ggml-base.bin).

Кнопка **«Голоса…»** в панели озвучивания открывает каталог Piper. Сейчас доступны русские голоса Денис и Дмитрий из официального репозитория [rhasspy/piper-voices](https://huggingface.co/rhasspy/piper-voices), версия моделей зафиксирована на `v1.0.0`; каждый пакет — примерно 60 МБ. Приложение показывает ссылку на карточку модели и лицензионные сведения, а скачивание начинается только после отдельного подтверждения; файл модели проверяется по SHA-256. После загрузки голос работает локально без интернета; пакет можно удалить из того же окна. Не скачивайте и не используйте голос, пока не проверили условия его карточки. Движок Piper 1.8.0 распространяется под GPL-3.0-or-later; файл лицензии и ссылка на исходники включены в Windows-сборку. Установленные голоса Windows и онлайн-голоса Edge TTS остаются отдельными вариантами.

## Мастерская и проекты

С боковой панели откройте **«Мастерская»** или нажмите `Ctrl + Shift + P`: сохраняйте исследовательские проекты с локальной сводкой, собирайте цитаты с адресами источников, возвращайтесь к недавно закрытым страницам и включайте необязательные забавные эффекты. Снимки проектов исключают приватные вкладки; сохранение цитаты из приватной вкладки требует отдельного подтверждения.

## Запуск из исходников

Требуется Node.js 18+.

```bash
npm install
npm start        # веб-версия → http://localhost:3000
```

Десктопная версия (Electron) для разработки:

```bash
npm run app
```

Сборка portable `.exe` под Windows (нужны Python 3.12 и CMake для подготовки локальных Piper/Whisper runtime):

```powershell
./scripts/build-piper-runtime.ps1
./scripts/build-whisper-runtime.ps1
npm ci
npm run dist:win   # результат появится в release/
```

GitHub Actions собирает оба runtime из закреплённых исходников, автоматически упаковывает приложение и публикует Windows-сборку в Releases. Модель Whisper в `.exe` не включается.

## Как это работает

- `server.js` — Express-сервер: статика + API
  - `/api/search?q=` — реальная поисковая выдача (DuckDuckGo), которую ByAzen рисует в своём интерфейсе
  - `/api/suggest?q=` — подсказки при вводе
  - `/api/weather` — погода, `/api/favicon?domain=` — фавиконки с офлайн-заглушкой
  - `/proxy?url=` — прокси: снимает `X-Frame-Options`/CSP, перехватывает ссылки и формы, синхронизирует заголовок и URL вкладки через `postMessage`
- `public/index.html` — весь интерфейс и логика браузера, без фреймворков
- `public/fonts/` — Inter и Inter Tight лежат локально, внешних стилей в `<head>` нет (иначе недоступный Google Fonts блокирует отрисовку и JS — белый экран)
- `electron/` — обёртка для десктопа: поднимает тот же сервер на свободном локальном порту и открывает его в нативном окне без рамок

```
byazen/
├── assets/          # иконка приложения (.png / .ico)
├── electron/        # main + preload для Electron
├── public/          # интерфейс браузера (index.html, icon.png, fonts/)
├── server.js        # сервер: поиск, подсказки, прокси
└── package.json
```

## Ограничения

В Windows-приложении сайты открываются в изолированных вкладках Chromium, а не в iframe — так страницы загружаются со своими скриптами, стилями и кодировкой. В веб-версии используется локальный прокси, поэтому отдельные сложные сайты там могут работать не полностью. Для таких случаев используйте кнопку «Открыть сайт в системном браузере» вверху боковой панели.

## Если вместо интерфейса белый экран

1. Обновите страницу с очисткой кэша: `Ctrl + Shift + R` (в Electron — `Ctrl + R`).
2. Убедитесь, что открываете адрес запущенного сервера: `npm start` → `http://localhost:3000`. При статическом хостинге отдавайте содержимое `public/` как корень сайта.
3. Все внешние запросы имеют таймаут, а при сбое JavaScript ByAzen показывает плашку с текстом ошибки вместо пустого экрана — пришлите её из консоли (F12), если проблема повторится.
