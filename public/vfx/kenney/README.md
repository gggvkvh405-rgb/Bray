# Kenney Particle Pack assets

The following locally bundled sprites are used by ByAzen's photo-code effects: `fire_01.png`, `flame_01.png`, `smoke_01.png`, `flare_01.png`, `spark_01.png`, `star_01.png`, and `muzzle_01.png`.

- Original pack: [Kenney Particle Pack](https://kenney.nl/assets/particle-pack)
- GitHub mirror/source manifest: [Tiddybub/2d-assets — effects/particle-pack](https://github.com/Tiddybub/2d-assets/tree/main/effects/particle-pack)
- License: CC0 1.0; the original pack's license notice is included as `LICENSE.txt`.

The sprites are bundled locally and recolored/animated in the browser canvas; ByAzen does not fetch effect assets from the network at runtime.
